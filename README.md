# STORM TASK MANAGER

## **О проекте**
STORM TASK MANAGER — высокоинформативный диспетчер задач и монитор процессов Windows. Предоставляет детальный контроль за потоками, дескрипторами (Handles), загруженными DLL-модулями, сетевыми соединениями и энергопотреблением приложений.

## **Происхождение и форки**
Оригинальная разработка ReiKatari.

## **Технологический стек**
- **Языки программирования**: TypeScript, C++, C# (.NET)
- **Интерфейс**: React, Tailwind CSS, Electron
- **Системные API**: Windows Toolhelp32, NtQuerySystemInformation, Performance Counters

## **Ключевые возможности**
- **Детальный анализ процессов**: Просмотр дерева процессов, командной строки запуска, переменных окружения и используемых модулей.
- **Мониторинг открытых дескрипторов (Handles)**: Определение процессов, блокирующих удаление или перемещение файлов.
- **Сетевой монитор процессов**: Просмотр всех активных TCP/UDP соединений с определением удаленных IP-адресов и портов.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64)

## **Установка и запуск**
1. Скачайте установщик из раздела **Releases** на GitHub.
2. Запустите приложение с правами Администратора для полного доступа ко всем системным процессам.

## **Безопасность и цифровые подписи**
Подписано сертификатом **CN=STORM SOFT, O=STORM EDEN** (SHA-256 Authenticode).
